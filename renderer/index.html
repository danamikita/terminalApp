IDE launch rules

      

        Each rule matches files/folders in a project and launches a command. Use {file} for the matched
        file's full path, or {folder} for the project folder's path. A command that's just
        {file} or {folder} opens that path with its registered app instead of running a
        command line. "Always offered" rules need no match and are offered for every folder.
